# 🎉 Mina Pozivnica API

Backend aplikacija za digitalne pozivnice i RSVP sistem.  
Napravljen u **Node.js + Express + MongoDB (Mongoose)**, sa admin panel funkcionalnostima.

---

## 🚀 Funkcionalnosti

- 📩 Kreiranje pozivnica (porodica + članovi)
- 🔍 Pretraga po imenu/porodici (`searchKey` normalizacija srpskih slova)
- 📝 RSVP potvrda ili odbijanje
- 📊 Admin pregled svih odgovora
- 📈 Statistika (broj gostiju, prihvaćenih/odbijenih itd.)

---

## 🛠 Tehnologije

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [MongoDB Atlas](https://www.mongodb.com/atlas)
- [Mongoose](https://mongoosejs.com/)
- [Helmet](https://helmetjs.github.io/) (security headers)
- [CORS](https://github.com/expressjs/cors)
- [Compression](https://github.com/expressjs/compression)
- [Express Rate Limit](https://github.com/nfriedly/express-rate-limit)
- [Morgan](https://github.com/expressjs/morgan)
- [Chalk](https://github.com/chalk/chalk)
